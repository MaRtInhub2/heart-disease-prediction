Проект по разработке и валидации алгоритма бинарной классификации для раннего выявления сердечно-сосудистых патологий на основе комплекса клинических биомаркеров и анамнестических данных.

---

## 📌 Постановка задачи и бизнес/клинический контекст
Сердечно-сосудистые заболевания (ССЗ) остаются ведущей причиной летальности во всем мире. Задержка или ошибка в постановке диагноза несет критический риск для жизни пациента.

* **Цель**: разработать надежную предиктивную модель, способную по клиническим признакам выявлять наличие сердечной патологии (`HeartDisease` = 1) с максимальной полнотой (**Recall**), минимизируя вероятность пропуска больного (False Negatives).
* **Специфика медицинской задачи**: ошибка первого рода (ложная тревога) стоит клинике лишь дополнительного обследования, тогда как ошибка второго рода (пропуск патологии) опасна летальным исходом.

---

## 📊 Данные и разведочный анализ (EDA)
Датасет содержит 918 клинических наблюдений по 11 ключевым признакам:

| Признак | Описание | Тип |
| :--- | :--- | :--- |
| `Age` | Возраст пациента | Числовой |
| `Sex` | Пол (M, F) | Категориальный |
| `ChestPainType` | Тип боли в груди (TA, ATA, NAP, ASY) | Категориальный |
| `RestingBP` | Артериальное давление в покое (мм рт. ст.) | Числовой |
| `Cholesterol` | Уровень сывороточного холестерина (мг/дл) | Числовой |
| `FastingBS` | Сахар крови натощак (> 120 мг/дл) | Бинарный |
| `RestingECG` | Результаты ЭКГ в покое (Normal, ST, LVH) | Категориальный |
| `MaxHR` | Максимальный достигнутый пульс | Числовой |
| `ExerciseAngina` | Стенокардия при физ. нагрузке (Y, N) | Категориальный |
| `Oldpeak` | Депрессия сегмента ST при нагрузке | Числовой |
| `ST_Slope` | Наклон пикового сегмента ST (Up, Flat, Down) | Категориальный |
| **`HeartDisease`** | **Целевой признак** (1 = патология, 0 = норма) | **Target** |

### Ключевые инсайты EDA:
1. **Баланс классов**: в выборке умеренное распределение (55% больных, 45% здоровых), дисбаланс незначительный.
2. **Факторы риска**: наивысшая положительная корреляция с заболеванием у показателей `Oldpeak`, `ExerciseAngina=Y` и типа стенокардии `ASY` (асимптомная ишемия).
3. **Защитные факторы**: более высокий `MaxHR` (максимальный пульс) и подъем ST сегмента (`ST_Slope=Up`) сильно ассоциированы со здоровым сердцем.

## 🛡️ Архитектура валидации и защита от утечки данных (Data Leakage)
В проекте реализована строгая схема препроцессинга:
1. **Стратифицированное разбиение (`StratifiedKFold` / `train_test_split`)**:
   * Разделение на train (80%) и holdout test (20%) с сохранением точных долей классов (`stratify=y`).
2. **Изоляция скейлинга**:
   * Для предотвращения Data Leakage нормализация `StandardScaler` признаков `['Age', 'RestingBP', 'Cholesterol', 'MaxHR', 'Oldpeak']` обучается **исключительно** на train (`fit_transform`) и применяется к test только через `transform`. Статистики теста не попадают в модель на этапе обучения.
3. **One-Hot Encoding**: кодирование категориальных шкал с `drop_first=True` во избежание мультиколлинеарности.

## 🏆 Результаты моделирования

В качестве базовой модели был исследован ансамбль решающих деревьев **Random Forest Classifier** (`n_estimators=100`, `max_depth=5`, `random_state=42`).

### Метрики на отложенной тестовой выборке (Holdout Test, n = 184):
* **ROC-AUC**: `0.9275`
* **Accuracy**: `0.85`
* **Macro Avg F1-Score**: `0.85`

#### Classification Report:
```text

           1       0.86      0.87      0.87       102

    accuracy                           0.85       184
   macro avg       0.85      0.85      0.85       184
weighted avg       0.85      0.85      0.85       184
```

### 🎯 Тюнинг порога классификации (Threshold Tuning)
При стандартном пороге $p = 0.50$ модель показывает полноту $Recall = 0.87$ (13 пропущенных больных из 102).
Путем сдвига порога вероятности классификации отсечения (Threshold Tuning) в сторону чувствительности ($p = 0.35$–$0.40$):
* Полнота (**Recall**) для целевого класса риска повышена **до 0.96** (число ложноотрицательных пропусков снижено более чем в 3 раза).
* Модель адаптирована под жесткие требования медицинского скрининга без необходимости переобучения весов.
